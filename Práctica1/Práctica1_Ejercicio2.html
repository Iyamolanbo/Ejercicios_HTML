Primera parte: Lista de definición (rellenar los <dd>)

Escribe una definición clara y breve para cada elemento.

<title>
Se trata de una etiqueta que sirve para indicar el nombre de la página web en la pestaña de esta. Se ubica en la cabecera <head>...</head>
<meta>
Metadatos (datos de los datos) que le dotan a una página web de atributos propios tales, como el conjunto de caracteres, la descripción, el ancho o el autor, entre otros. Van ubicados en la cabecera <head>...</head>
<strong>
Etiqueta que sirve para (poner en negrita) una palabra. A diferencia de su congénere <b>...</b> cuenta con sistema de posicionamiento. Se ubica principalmente en el body <body>...</body>
<ul>, <ol>, <li>
Etiquetas que sirven para crear listas desordenadas, listas ordenadas y listar los diferentes elementos. Se ubican principalmente en el body <body>...</body>
<div>
Etiqueta que sirve para dividir en bloques una página web. Se ubica principalmente en el body <body>...</body>
<blockquote>
Etiqueta que sirve para crear una cita, frase o pensamiento. No va suelta sin más, sino que ha de utilizarse junto a la etiqueta <p>...</p> a fin de recoger dicho pensamiento. Se ubica principalmente en el body <body>...</body>
<pre>
Es una etiqueta bastante particular ya que todo cuanto se escriba en ella se reflejará preformateada en el navegador. Se ubica principalmente en el body <body>...</body>

Segunda parte: Lista

  • Estructura básica de un documento
    1. Doctype y ráiz
      • !DOCTYPE html
      • html lang="es"
    2. Cabecera (head)
      • title
      • meta charset="UTF-8"
      • meta name="description
    3. Cuerpo (body)
      • Encabezados y párrafos
        • h1...h6
        • p
      • Texto en línea
        • strong(importancia)
        • em(énfasis)
        • mark, small, s, sub, sup
  • Listas en HTML
    • No ordenadas (ul)
    • Ordenadas (ol)
    • Definición (dl)
      1. dt-término
      2. dd-descripción
    • Anidación de listas
      • Subtemas con ul; dentro de li
      • Subpasos con ol dentro de li
  • Enlaces e imágenes
    1. Enlaces (a href="..." target="...")
      • Internos (anclas con #id)
      • Externos (nueva pestaña con _blank)
    2. Imágnes(img src="..." alt="..." title="...")
      • Atributos obligatorios y accesibilidad
  • Agrupación y separadores
    • div para agrupar bloques
    • hr para separar secciones
    • blockquote para citas largas
    • pre para texto preformateado
